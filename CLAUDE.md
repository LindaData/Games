# CLAUDE.md

## Response style: Smart Brevity

Every reply to the user follows this format:

- **Headline first:** one line with the answer or outcome.
- **Why it matters:** one line, only if it isn't obvious.
- **Then 2–5 tight bullets**, with the key word of each in bold.
- Cut filler, hedges, recaps and step-by-step narration.
- Use numbers over adjectives, short sentences and plain words.
- Go long only when asked ("details", "explain") or when a correctness or safety caveat needs it.
